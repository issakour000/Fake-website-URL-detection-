# Fake-website-URL-detection-
The Phishing Detection System is a lightweight desktop application that detects phishing URLs with a hybrid approach. It combines a rule-based heuristic engine with a Logistic Regression model written from scratch. It is built entirely in Core Java and uses no external databases such as MySQL or MongoDB, and no external machine learning libraries such as TensorFlow or Weka. This keeps the system transparent, portable, and easy to study.
The application has a tabbed dashboard. The URL Scanner checks a single link and returns a risk score and a verdict of Safe, Suspicious, or Phishing. The Batch Processor scans many URLs at once. The History and Statistics tab shows each user’s past scans in a table, along with a pie chart of the Safe, Suspicious, and Phishing percentages. The ML Model tab lets you load a dataset, train the model, see its accuracy, F1 score, and confusion matrix, and test predictions by hand. A Simulation panel is also included for experimenting with URLs.


Main.java is the entry point. It applies the UI settings, tries to load a pre-trained ML model, and launches the login screen. LoginFrame.java handles logging in and routes new users to registration. DashboardFrame.java is the main interface: it holds all the tabs and coordinates background scanning.

DataBaseConnection.java is the data access layer. It reads and writes the text files, hashes passwords, and saves and retrieves scan history. FeatureExtractor.java is the rules engine. It breaks a URL into scheme, host, and path and runs heuristic tests that add risk points. MLModel.java implements Logistic Regression from scratch: it parses datasets, builds feature vectors, trains weights with gradient descent, saves the model, and serves predictions. MLPanel.java is the interface for loading a CSV, starting training, viewing metrics, and testing the model manually. BentoTheme.java holds the color palette and typography rules, and BentoCard.java is a custom rounded panel that keeps padding consistent.
